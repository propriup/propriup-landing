# Guide — Mettre le site en ligne et le modifier (pour Céline)

## 1) Créer un compte GitHub (gratuit)
- Va sur **github.com** → « Sign up ». Choisis un identifiant, ton email, un mot de passe.

## 2) Créer le dépôt (repository)
- En haut à droite, « **+** » → « **New repository** ».
- Nom : `propriup-landing`. Coche **Public**. Clique « Create repository ».

## 3) Envoyer les fichiers
- Sur la page du dépôt : « **uploading an existing file** » (ou Add file → Upload files).
- **Glisse-dépose tout le contenu** du dossier `propriup-landing` : le fichier `index.html`, `README.md`, **et le dossier `assets`** (toutes les images).
- En bas, clique « **Commit changes** ».

## 4) Mettre le site en ligne (gratuit)
- **Settings** (du dépôt) → **Pages** → Source : « Deploy from a branch » → branche **main**, dossier **/ (root)** → **Save**.
- Après ~1 minute, ton site est en ligne à :
  `https://TON-IDENTIFIANT.github.io/propriup-landing/`

## 5) Modifier le site avec ChatGPT
1. Ouvre `index.html` (sur GitHub, clique dessus), copie **tout** son contenu.
2. Colle-le dans **ChatGPT** avec ta demande (ex. « change ce texte », « mets cette couleur », « ajoute une section »).
3. ChatGPT te renvoie le nouveau `index.html`.
4. Sur GitHub : ouvre `index.html` → icône **crayon** (Edit) → efface tout, colle le nouveau → « **Commit changes** ». Le site se met à jour tout seul.

**Changer une image** : remplace le fichier correspondant dans le dossier `assets` (garde le même nom).

## Avant d'ouvrir au public
- **Formulaire** : dans `index.html`, remplace `REMPLACER_PAR_TON_ID` par ton identifiant **Formspree** (formspree.io, gratuit) pour recevoir les demandes.
- **Email** de contact à vérifier. Téléphone `07 52 63 62 36` OK.
- Les images (villa, intérieurs, terroir, visages d'avis) sont **générées** — remplace-les par tes vraies photos quand tu veux.
